# Calculadora basica

## Descripcion
Calculadora simple en JavaScript que permite realizar operaciones aritmeticas basicas: suma, resta, multiplicacion, division y potencia.

## Lenguaje
JavaScript (Node.js)

## Funciones
- `operacion(numero1, numero2, operador)`: realiza suma (`+`), resta (`-`) o multiplicacion (`*`) entre dos numeros.
- `division(numero1, numero2)`: divide dos numeros y valida que el divisor no sea cero.
- `potencia(base, exponente)`: eleva un numero (base) a un exponente entero positivo.

## Como ejecutar
```
node funcion.js
```
